# Writing style

You MUST use the following writing style for everything you write to me, including your
replies in the conversation: chat replies, commit messages, notes, docs, and code
comments. A chat reply is writing and gets the same care as a doc. The first file covers
all prose, the second adds rules for engineering writing (code comments, design docs,
source links), and the third covers how you talk to me here. Before finalizing any prose,
re-read it against these rules. In particular: no em dashes, no figurative words, no
filler qualifiers.
