# Agent instructions

Shared writing instructions for coding agents.

[`AGENTS.md`](AGENTS.md) is the entry point. It imports the three writing-style files in
this directory:

- [`writing-style.md`](writing-style.md) covers tone, brevity, and formatting.
- [`writing-style-technical.md`](writing-style-technical.md) adds rules for technical
  writing and code comments.
- [`writing-style-conversation.md`](writing-style-conversation.md) covers chat
  responses.

Copy or symlink these files into the instruction location supported by your coding
agent. Keep them together so the relative imports continue to work.
