# Writing style

Apply the shared prose rules to all writing, including chat replies, documents,
commit messages, and code comments, respecting the agent-facing scope defined
in the shared guide. Before finalizing prose, check it against the applicable guides.

@writing-style.md

For chat replies to the user, also apply the conversation guide. Its answer
structure does not prescribe the structure of documents written during the task.

@writing-style-conversation.md

Before writing or revising engineering content, read `writing-style-technical.md`
in this directory. It covers PR descriptions, investigations, proposals, handoffs,
status updates, design docs, review replies, code comments, and source links.
Apply the sections relevant to the output.
